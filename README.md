# MÉVORA BUSINESS — V1

بداية مشروع تطبيق إدارة شركة MÉVORA.

## الموجود في النسخة الأولية
- Dashboard
- مخزون وإضافة/حذف منتجات
- شاشة المبيعات والفواتير
- شاشة الشركاء
- شاشة التقارير
- الهوية البصرية واللوجو المرفق
- دعم RTL والعربية والجنيه المصري

## التشغيل
1. ثبّت Flutter وAndroid Studio.
2. افتح مجلد المشروع في Android Studio أو VS Code.
3. شغّل: `flutter pub get`
4. شغّل: `flutter run`
5. لإنتاج APK: `flutter build apk --release`

## المرحلة التالية
ربط Firebase/Cloud Firestore لإتاحة نفس البيانات لك ولشريكك، ثم إضافة الحسابات والصلاحيات، الفواتير الكاملة، الآجل والدفعات، المرتجعات، المصروفات والمدخلات، وسجل العمليات.
